# Physics II Full Final Review Randomizer

GitHub Pages-ready static site.

## Files
- index.html
- questions.js

## Features
- 198 MC questions
- 22 questions per topic
- No images
- No AI explanation button
- No repeated questions within a generated set
- Topic filter
- Custom question count
- 50/50 standard + challenge option
- Submit/check answer, previous/next, finish summary
- Review missed only mode
- Local browser session saving

## Upload
Unzip and upload index.html and questions.js to the root of your GitHub Pages repo or folder.
